# Pre-send to participants

Send ~3 weeks before 3 October, reminder the week of. Attach nothing large;
link the repo and the data zip. Keep the papers optional.

---

Subject: ISSW Saturday workshop — laptop setup (or come and watch)

We are looking forward to the autoATES v3.0 workshop on Saturday
3 October, 09:00–16:00, Aava Hotel Peak Room.

You can follow along on a laptop or sit and watch. Both are intended.
Prior GIS or Python helps if you want to run the models yourself;
beginners are welcome on the observe track.

**Live site.** We will map Connaught Creek, Rogers Pass (13 km²), on the
same kind of global data used for the western Canada production run
(ALOS 30 m elevation, Sentinel-2 forest). That is the drainage from the
comparison talks. A precomputed map of the Whistler-area South Coast
benchmark will be available to open in QGIS; we will not run that live.

**If you want to follow along, do this before Saturday:**

1. Install QGIS 3 from https://qgis.org
2. Follow SETUP.md in the workshop repository:
   https://github.com/AutoATES/issw2026-autoates-workshop
3. Download the Connaught data zip from the GitHub Release (link in
   SETUP.md) and unpack it into the repo’s `data/` folder.
4. Run the one-line import check in SETUP.md. If it prints `ok`, you are
   done.

Helpers will be in the room from 08:15 with USB copies. Hotel wifi is not
a plan — bring the repo and the zip on disk.

**If the install fails, come anyway.** You will see every step on the
projector, and you can run the notebooks later from the same repository.

Optional background (not required): the ISSW autoATES v3.0 extended
abstract.

See you Saturday.
  John, with colleagues from SFU and BFW
