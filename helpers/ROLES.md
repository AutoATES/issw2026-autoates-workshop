notebooks. Do not all float.

| Projector / narrative | John | SFU |

| QGIS + jump-ahead | SFU or BFW | Door |
| Flow-Py / AvaFrame | BFW | BFW |

Fill names the week of the workshop.

## Door / Windows / conda (08:15–12:00)

- USB, hotspot, `SETUP.md` pass/fail.
- Ten-minute rule: if it is not importing, they observe until lunch.
- Do not start a from-scratch Anaconda install at 09:10.

## QGIS + jump-ahead

- Know the path for every `outputs_reference/` folder.
- Load ATES `.qml` from `qgis/`.
- Phrase: “copy this folder, then open the next notebook.”

## Flow-Py (afternoon)

- Own notebook 04.
- If a run is still going at 14:35, kill it and load reference outputs.
- Typical failures: mixed GDAL, path with spaces, conda env not active,
  trying to run South Coast, trying to run 5 m lidar.

## PRA + classifier

- Own the typical vs infrequent explanation and the floor/average story.
- Keep people off parameter-tweaking. The workshop config is frozen.
